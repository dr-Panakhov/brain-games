«Игры разума» — это пакет из пяти консольных игр, созданных по принципу популярных мобильных приложений для тренировки мозга. Проект разработан в рамках обучения на платформе Hexlet.

## Описание игр:
*   **Чётное число:** Определение чётности случайного числа.
*   **Калькулятор:** Вычисление случайных арифметических выражений.
*   **НОД:** Нахождение наибольшего общего делителя двух чисел.
*   **Прогрессия:** Поиск пропущенного элемента в арифметической прогрессии.
*   **Простое число:** Определение, является ли число простым.

## Стек технологий и инструменты:
*   **Language:** Python 3.x
*   **Project Manager:** `uv` (современный и быстрый менеджер пакетов и окружения)
*   **Linter:** `ruff` (контроль стиля кода и архитектуры по стандартам PEP8)
*   **Архитектура:** Модульная структура, изоляция побочных эффектов, чистые функции.

Для работы проекта необходим установленный менеджер пакетов `uv`.

# Перейти в директорию проекта
